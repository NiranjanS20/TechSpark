# 🎉 TechSpark 2026 – Event Website

A responsive **Event Website** built using **HTML5, CSS3, and Bootstrap 5**.  
This project is designed for showcasing a tech or college-level event with sections like event details, schedule, speakers, and registration.

---

## 📌 Features

- Responsive design (mobile-first)
- Built with Bootstrap 5
- Clean and modern UI
- Smooth scrolling
- Reusable and well-structured code
- No backend required

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the website  
- **CSS3** – Custom styling  
- **Bootstrap 5** – Layout, responsiveness, components  
- **Font Awesome** – Icons  

---

## 📂 Project Structure

TechSpark-Event-Website/
│
├── index.html
├── style.css
└── README.md


---

## 📄 Sections Included

- **Navbar** – Sticky navigation bar
- **Hero Section** – Event name, date, location, CTA
- **About Section** – Event highlights
- **Schedule Section** – Day-wise event plan
- **Speakers Section** – Featured speakers
- **Registration Section** – User registration form
- **Contact Section** – Contact details
- **Footer** – Copyright info

---

## 🚀 How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Double-click `index.html`  
4. View the website in your browser  

No additional setup required.

---

## ✏️ Customization

You can easily:
- Change event name, date, and location
- Update colors in `style.css`
- Add or remove sections
- Replace speaker images and details
- Integrate backend or JavaScript later
